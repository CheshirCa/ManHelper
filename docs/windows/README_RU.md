# ManHelper для Windows: установка и использование

ManHelper 0.5.4 — приложение в области уведомлений Windows для поиска
Linux man-страниц во время работы с PuTTY или KiTTY. Оно читает уже
скопированный Unicode-текст, разбирает командные строки в стиле shell без их
исполнения и ищет справку в локальной SQLite-базе, открытой только для чтения.

## Требования

- 64-разрядная Windows 10 или Windows 11;
- PuTTY или KiTTY при стандартной настройке списка терминалов;
- файлы `ManHelper.exe` и `manbase.sqlite` из релизного архива.

Для переносимой сборки не нужны Python, Linux-подсистема или установщик.

## Установка переносимой сборки

1. Скачайте `ManHelper-0.5.4-windows-x64.zip` со страницы GitHub Releases.
2. При необходимости сравните хеш архива с опубликованной контрольной суммой.
3. Полностью распакуйте ZIP в отдельную папку.
4. Оставьте `ManHelper.exe` и `manbase.sqlite` в одной папке.
5. Запустите `ManHelper.exe`.

Значок приложения появится в области уведомлений Windows и может находиться в
меню скрытых значков. Заметки, закладки, история и сохранённые настройки
хранятся отдельно:

```text
%LOCALAPPDATA%\ManHelper\man-user.sqlite
```

Замена папки переносимой программы или файла `manbase.sqlite` не удаляет эту
пользовательскую базу.

## Основное использование

1. Выделите команду или командную строку в PuTTY либо KiTTY.
2. Скопируйте её обычным способом.
3. Нажмите `Ctrl+F1`.
4. Если подходят несколько секций справки, выберите нужный результат во
   всплывающем окне.
5. Откройте подробности для чтения полного текста, исходного roff или
   сохранённых секций.

Во всплывающем окне доступны явные действия копирования, открытия подробностей
и веб-поиска. Окно подробностей поддерживает навигацию по командам, страницам
и секциям, локальный Unicode-поиск, копирование показанного текста, заметки и
закладки. Через меню значка открываются закладки и история, настройки и выход.

ManHelper никогда не отправляет `Ctrl+C` в терминал и не исполняет выделенный
текст. Глобальная горячая клавиша читает текущий буфер обмена, только если
активный процесс соответствует настроенному терминалу.

## Настройки

При первом запуске действуют встроенные значения. Для начальной ручной
настройки скопируйте `settings.example.ini` в:

```text
%LOCALAPPDATA%\ManHelper\settings.ini
```

Поддерживаемые параметры:

```ini
[General]
terminal_processes = putty.exe,kitty.exe
clipboard_limit = 4096
hotkey = Ctrl+F1
database_path = manbase.sqlite
interface_language = ru
web_search_template = https://www.google.com/search?q={query}
browser_url_limit = 2048
```

- `terminal_processes` — имена исполняемых файлов через запятую.
- `clipboard_limit` ограничивается диапазоном 256–65536 символов.
- `hotkey` поддерживает `Ctrl`, `Alt`, `Shift` или `Win` вместе с `F1`–`F12`.
- Относительный `database_path` отсчитывается от папки `ManHelper.exe`.
  Поддерживаются также абсолютные пути с буквой диска и UNC-пути.
- `interface_language` принимает `ru` или `en`; по умолчанию используется
  русский.
- `web_search_template` должен начинаться с `http://` или `https://` и
  содержать точный маркер `{query}`.
- `browser_url_limit` ограничивается диапазоном 256–8192 символов.

Язык, шаблон веб-поиска и лимит URL также сохраняются в пользовательской базе
и редактируются через окно «Настройки» из меню значка. Для применения всех
изменений перезапустите ManHelper.

## Если горячая клавиша не работает

- Убедитесь, что значок программы остаётся в области уведомлений.
- Проверьте, не занято ли это сочетание другой программой.
- Скопируйте текст до нажатия горячей клавиши.
- Убедитесь, что активно окно одного из настроенных терминальных процессов.
- При необходимости задайте в `settings.ini` другое поддерживаемое сочетание.

## Сборка из исходников

Сборка необязательна и не нужна для использования переносимого релиза.

Требования:

- PureBasic x64;
- Visual Studio C++ x64 Build Tools;
- PowerShell;
- включённый в проект SQLite amalgamation в
  `windows/validator/vendor/sqlite`.

Из корня репозитория:

```powershell
cd windows\manhelper
.\build.ps1
```

GUI-программа будет создана как `build\ManHelper.exe` без консольного окна.

Валидатор собирается отдельно:

```powershell
cd ..\validator
.\build.ps1
```

Будут созданы `build\ManBaseValidator.exe` и
`build\ManBaseValidatorGUI.exe`. Примеры запуска валидатора:

```powershell
.\build\ManBaseValidator.exe --database C:\data\manbase.sqlite
.\build\ManBaseValidator.exe --database C:\data\manbase.sqlite --report report.json
.\build\ManBaseValidatorGUI.exe --database C:\data\manbase.sqlite
```
