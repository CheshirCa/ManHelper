# Changelog

## 0.2.0 - 2026-07-28

- Added a resizable Russian-language Validator GUI without a console window.
- Added database selection, issue table, issue details and text/JSON export.
- Extracted a shared validation runner used by both CLI and GUI.
- Added GUI smoke and PE subsystem regression tests.

## 0.1.0 - 2026-07-28

- Added standalone ManBase Validator CLI.
- Added read-only SQLite opening and unchanged-file verification.
- Added schema, compatibility, integrity, checksum, encoding, content and FTS5 checks.
- Added plain-text and JSON reports with documented exit codes.
- Added PureBasic unit tests and an integration test against the Linux Builder database.
