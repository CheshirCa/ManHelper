# GitHub Release assets

Publish `ManHelper-0.5.4-windows-x64.zip` as a GitHub Release asset instead of
committing it to the repository. The archive contains:

- `ManHelper.exe`;
- the updated `manbase.sqlite`;
- Russian and English quick-start files;
- `settings.example.ini`;
- `LICENSE.txt`;
- per-file SHA-256 checksums.

The archive checksum is stored in `SHA256SUMS.txt`.
